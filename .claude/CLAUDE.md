# Project guidance

Read and follow [`AGENTS.md`](../AGENTS.md), the authoritative shared project guidance. Read ignored `AGENTS.local.md` at the repository root when present; never copy its private machine instructions into publishable output.

This is Usage Monitor for Codex, using the historical internal package name `usage_monitor_for_claude`. Windows and experimental Linux platform support share a fixed local Codex app-server provider boundary. Upstream provider networking, credential handling, billing and prepaid features are not active Codex capabilities.

The owner-authorized full rebase and Linux migration are described in [`UPSTREAM_SYNC.md`](../UPSTREAM_SYNC.md). Ordinary reviews do not authorize changes or external actions. Invoke advisory Claude review only when explicitly requested for a named artifact or included in a specifically invoked workflow. Never commit, push, tag, merge, publish, deploy, or restart from an inferred authorization.
